1. 対象

本ポリシーは、開発者個人が自分の Google アカウントのために使う個人用アプリ（以下「本アプリ」）に適用されます。本アプリは一般には配布しておらず、利用者は開発者本人のみです。開発者が運営するサーバーやウェブサービスはありません。

2. アクセスする情報

本アプリは、利用者が Google の同意画面で許可した範囲に限り、YouTube API Services を通じて、利用者本人の YouTube アカウントの情報にアクセスします。氏名やメールアドレスなど、それ以外の個人情報は取得しません。

3. 利用目的

取得した情報は、開発者本人の個人的な利用の範囲でのみ使います。広告、プロファイリング、販売などの目的には使いません。

4. 共有

取得した情報を、第三者に販売・譲渡しません。

5. 保持・削除・許可の取り消し

保存したデータは、利用者本人がいつでも削除できます。Google アカウントのサードパーティのアクセス管理から、本アプリへの許可をいつでも取り消せます。

6. YouTube API Services と Google の方針

本アプリは YouTube API Services を使用しています。本アプリを使うことで、利用者は YouTube 利用規約に拘束されます。Google によるデータの取り扱いについては Google プライバシー ポリシーをご覧ください。本アプリによる、Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシーに準拠します。

7. このページ

このページには Cookie やアクセス解析を設置していません。

8. 変更・お問い合わせ

本ポリシーを変更する場合は、このページを更新します。個人用アプリのため、お問い合わせの受付は行っていません。

Privacy Policy

Last updated: 2026-11-23 / Home

1. Scope

This policy applies to a personal application (the "App") that its developer uses for the developer's own Google account. The App is not distributed to the public, and the developer is its only user. The developer does not operate any server or web service for the App.

2. Information accessed

Only to the extent the user permits on the Google consent screen, the App accesses information in the user's own YouTube account through YouTube API Services. The App does not collect other personal information such as name or email address.

3. Use

Retrieved information is used only for the developer's own personal use. It is not used for advertising, profiling or sale.

4. Sharing

Retrieved information is not sold or transferred to third parties.

5. Retention, deletion and revoking access

The user can delete stored data at any time. The user can revoke the App's access at any time from the third-party access settings of the Google Account.

6. YouTube API Services and Google policies

The App uses YouTube API Services. By using the App, users are bound by the YouTube Terms of Service. For how Google handles data, see the Google Privacy Policy. The App's use of information received from Google APIs adheres to the Google API Services User Data Policy.

7. This page

This page does not use cookies or analytics.

8. Changes and contact

If this policy changes, this page will be updated. Because this is a personal application, no contact channel is provided.
